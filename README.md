## Featured projects

> These repositories are private; I'm happy to walk through them on request.

### 🧭 [Orchestrator Agent](https://orchestrator-agent.pages.dev) — live demo
A hybrid, LangGraph-based orchestrator that routes each query to domain specialist agents using semantic search over a local knowledge base (ChromaDB + sentence-transformers). It supports multiple LLM backends (Ollama, LM Studio, Anthropic) with configurable fallback, MLflow tracing, and a guided **agent-builder flow** (specify → plan → tasks → implement) with human approval at every phase. Each specialist is defined by just a domain and a knowledge-base folder.

### 🛠️ AgentesIACreator
The v2 of the orchestrator: a personal multi-agent system built on **Microsoft Agent Framework** that turns a request into a reviewable spec, plan, task list and code through Spec-Driven Development, with a human checkpoint at every stage. A **model router** picks the best provider and model per stage (local Ollama, free cloud tiers, Anthropic where it matters), confidential projects stay on local models only, and every stage is backed by its own evals.

### 📱 App Vínculo
A mobile app (React Native + Expo, Supabase backend) built with manual **Spec-Driven Development**: every feature has an approved spec, data model, technical plan and task checklist before any code. Privacy-first by design — Row Level Security on every table, age self-declaration, a code of conduct, moderated forums and a reporting/moderation workflow.
